# 組み立て（ユニバーサル基板・完成形の配線）

> PCB 化を進めている（2026-10-23〜）。回路図とフットプリントは [pcb.md](pcb.md)。この文書はユニバーサル基板の記録。

ブレッドボードとメス-メスのジャンパー線では接触が不安定で、トラックパッドの SPI が化けた（2026-10-13）。
ユニバーサル基板にはんだ付けして、配線を固定する。

## 全体像

```
 モバイルバッテリー（または PC）
        │ USB-C
        ▼
 ┌──────────────┐  +5V ───────────────┐
 │  CH9102F     │  GND ─────────────┐ │
 │ (USB-シリアル │  RxD ◀──────────┐ │ │
 │  + 給電入口)  │                 │ │ │
 └──────────────┘                 │ │ │
                                  │ │ │   ┌──────────────────────────┐
                                  │ │ └──▶│ 5V        ESP32-S3 ボード │
                                  │ └────▶│ GND     (ESP32-S3FH4R2)  │
                                  └───────│ TX(GPIO43)               │
                                          │                          │
   トラックパッド TM035035 ◀── 12P FFC ──▶ │ GPIO12 / 13 / 11 / 10 / 9│
   （FFC 変換基板経由）                    │ 3V3, GND                 │
                                          │                          │
                                          │ USB-C ── C-C ケーブル ── 7skb
                                          └──────────────────────────┘
                                                  │ BLE
                                                  ▼
                                                 Mac
```

- **電源は CH9102F の USB-C から入れる。** CH9102F の基板は CC に 5.1kΩ が付いているので、モバイルバッテリーでも PC でも 5V が出る。
  `+5V` ピンから S3 の `5V` ピンへ。S3 の 5V は USB-C の VBUS とつながっているので、7skb にも 5V が届く。
- **CH9102F は、ログの取り出し口も兼ねる**（S3 の TX → CH9102F の RxD）。PC につなげばログが見られ、バッテリーにつなげば電源だけになる。
- 秋月の Type-C DIP 化キット（5077CR）と 5.1kΩ は、**不要**になった。

実際の基板の配線図（持ち主作成）: [image/universal.png](image/universal.png)（元データ: `image/universal.xcf`、GIMP）

## 配線表

### CH9102F（CN3: 1×4 ピン）→ S3

| CH9102F CN3 | 信号 | 接続先 | 備考 |
|---|---|---|---|
| 1 | +5V | S3 の **5V** | 直結（ジャンパーは付けなかった。書き込み時は CH9102F の USB を抜く。下記） |
| 2 | GND | S3 の **GND** | |
| 3 | TxD | **どこにもつながない** | CH9102F の出力は 5V。S3 の GPIO は 5V 耐性なし |
| 4 | RxD | S3 の **TX（GPIO43）** | ログ（S3 → PC の片方向） |

CN2（VIO・DTR・RTS・CTS）は使わない。

### トラックパッド（12P FFC 変換基板）→ S3

> **番号の向きに注意（2026-10-15 にはまった）。** 下の表の「FFC 番号」は**トラックパッド側（J1）の番号**。
> 手元の組み合わせ（同方向の FFC + FPC 12P 変換基板）では、**変換基板の印字の番号と J1 の番号が逆順**だった
> （印字の 12 が J1 の 1 = SCK、印字の 1 が J1 の 12 = VDD）。印字どおりに配線すると、S3 の GPIO12 がパッドの VDD に、
> GPIO13 がパッドの GND につながり、パッドは一切応答しない（ID が 0x00）。
> 基板の配線はそのままで、**変換基板をソケットに 180° 回して挿したら動いた**。
>
> 見分け方（テスターなし）: S3 を PC に直結して `FEATURES="trackpad usb-log trackpad-probe trackpad-selftest" tools/hk flash` →
> `tools/hk usb-log`。`probe: pull-up drive GPIO12 low` で GPIO12 が 1 のまま・GPIO13 が常に 0 なら逆向き。
> 正しければ `selftest ... khz=2000 ...: single 0/300 bad` と `firmware id=0x07` が出る。

| FFC 番号 | 信号 | 接続先 |
|---|---|---|
| 1 | SCK | S3 **GPIO12** |
| 2 | MISO | S3 **GPIO13** |
| 3 | SS | S3 **GPIO10** |
| 4 | DR | S3 **GPIO9**（今のファームでは使っていないが、配線しておく） |
| 5 | MOSI | S3 **GPIO11** |
| 6, 7, 8 | BTN2, BTN3, BTN1 | つながない |
| 9, 10 | SCL, SDA | つながない（I²C 用） |
| 11 | GND | S3 **GND** |
| 12 | VDD | S3 **3V3**（**5V は不可**） |

### S3 の USB-C → 7skb

C-C ケーブルでつなぐ（基板上の配線はなし）。

## ピンの対応のまとめ（S3 側から）

| S3 のピン | つなぐもの |
|---|---|
| 5V | CH9102F +5V（直結） |
| GND | CH9102F GND・トラックパッド GND（共通にする） |
| 3V3 | トラックパッド VDD |
| TX（GPIO43） | CH9102F RxD |
| GPIO9 | トラックパッド DR |
| GPIO10 | トラックパッド SS |
| GPIO11 | トラックパッド MOSI |
| GPIO12 | トラックパッド SCK |
| GPIO13 | トラックパッド MISO |
| GPIO6 | 本体のボタン（MX スイッチのもう片方は GND。抵抗・ダイオードは不要。内部プルアップを使う） |
| USB-C | 7skb |

ボタンは最初 GPIO7 につなぐ予定だったが、この基板の GPIO7 の箇所が壊れていたので GPIO6 にした（2026-10-22。S3 の GPIO7 は無事）。

使わないピン: GPIO0（BOOT）、GPIO3・45・46（ストラッピング）、GPIO19/20（USB）、GPIO44（RX）など。

## 基板に組むときのポイント

### 1. 書き込むときは、CH9102F の USB を抜く（重要）

S3 に書き込むときは、S3 の USB-C を PC に挿す。このとき **CH9102F からの 5V がつながったままだと、電源同士がぶつかる。**
当初は CH9102F の `+5V` と S3 の `5V` の間に 2 ピンのピンヘッダ + ジャンパーピンを入れる計画だったが、**付けずに直結した**。
その代わり、書き込むときは CH9102F の USB ケーブルを抜いてから、S3 を PC に挿す。

### 2. モジュールは、ピンソケットで受ける（直付けしない）

S3・CH9102F・FFC 変換基板は、基板に**ピンソケット（メス）**をはんだ付けして、そこに挿す。
壊れたときの交換や、S3 を外して書き込むときに困らない。

### 3. SPI の配線は短く・まとめて

- トラックパッドの FFC 変換基板は、**S3 のすぐ近く**に置き、SCK・MISO・MOSI・SS は短く配線する。
- GND は、S3・CH9102F・トラックパッドで**共通**にする（星形にまとめるか、太めの線で）。
- 余裕があれば、トラックパッドの VDD（FFC の 12 番）と GND（11 番）の間、変換基板の近くに **0.1µF のセラミックコンデンサ**を入れる。電源のノイズが減る。

### 4. はんだ付けの後、通電前に確認すること（テスター）

- 5V と GND、3V3 と GND が**短絡していない**こと
- 表の各配線が**導通している**こと（特に FFC の 1〜5・11・12 番）
- CH9102F の **TxD がどこにもつながっていない**こと

## 動作確認

> **2026-10-15 の結果:** 変換基板を 180° 挿し直した後、`selftest` 2MHz で 0/300、ID `0x07`、キー入力とトラックパッド（感度 2X）が Mac で動作。
> CH9102F の受信が壊れていたため、手順 3 のログは `usb-log` の版（S3 を PC に直結）で確認した。テスターは未調達。

1. CH9102F の USB を抜き、S3 を PC に挿して書き込む（`FEATURES="trackpad trackpad-selftest trackpad-trace" tools/hk flash`）。
2. S3 を PC から抜き、CH9102F を PC に挿す。7skb を S3 の USB-C に挿す。
3. ログ（`tools/hk log`）で次を確認する。
   - `selftest mode=1 khz=2000 ...: single 0/300 bad, burst 0/300 bad`（SPI の配線が正しい）
   - `trackpad: relative mode, firmware id=0x07 version=0x3a`（パッドと通信できている）
   - `usb: keyboard ready`（7skb を認識）
4. Mac とつながり、キー入力とトラックパッドが動くこと。
5. CH9102F を**モバイルバッテリー**につなぎ替えて、同じように動くこと。数分〜数十分放置して、バッテリーが自動で切れないことも確認する。
