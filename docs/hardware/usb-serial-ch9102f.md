# USB-シリアル変換（秋月 AE-CH9102F-TYPEC-BO）

説明書: https://akizukidenshi.com/goodsaffix/AE-CH9102F-TYPEC-BO_20240730-web.pdf （Ver.2024-07-30）

S3 は USB-C をキーボード用のホストとして使うため、USB シリアル（ログ）が使えない。
その代わりに S3 の UART0（GPIO43 = TX）からログを出し、この変換モジュールで PC に取り込む。

## 仕様（抜粋）

| 項目 | 値 |
|---|---|
| IC | WCH CH9102F |
| 電源 | USB バスパワー 5V |
| 最大出力電流 | 約 300mA（基板上のリセッタブルヒューズで制限） |
| 信号電圧 | **5V（出荷時）**。J1 のジャンパ抵抗を 3.3 側へ移すと 3.3V |
| ボーレート | 50bps 〜 4Mbps |
| LED | T=送信 / R=受信 / P=電源 |

CN3（1×4）: `1 +5V` / `2 GND` / `3 TxD` / `4 RxD`
CN2（1×4）: `1 VIO` / `2 DTR` / `3 RTS` / `4 CTS`

## 開発中の使い方

```
CH9102F の +5V ──▶ S3 の 5V        （S3 とキーボードへの給電を兼ねる。上限約 300mA）
CH9102F の GND ──▶ S3 の GND
CH9102F の RxD ◀── S3 の TX (GPIO43)
```

- **S3 の TX → モジュールの RxD の 1 本だけ**つなぐ（片方向）。モジュールの TxD（5V 出力）は S3 の RX（GPIO44）につながない。S3 の GPIO は 5V 耐性がない。
- 出荷時は IO が 5V なので、S3（3.3V）からの信号を受けるだけでも気になる場合は、J1 のジャンパ抵抗を 3.3 側に移す（はんだごて作業）。
- ログは `/dev/ttyACM*` または `/dev/ttyUSB*` に現れる。115200bps。
- 以前は C3 を UART→USB 変換器にして同じことをしていた（TX を RX に誤配線して時間を使った。**TX 同士をつながないこと**）。

## 動作確認

2026-10-09: S3 の TX → CH9102F の RxD、+5V/GND で S3 とキーボードに給電する構成で、ログ取得（`/dev/ttyACM0`, `1a86:55d4`）と、7skb → S3 → BLE → Mac のパススルーを確認。

**2026-10-15: 受信（RxD）が効かなくなった。** 基板化のときにピンソケットを外そうとして、コテを長く当てた後から。S3 の 43 番と RxD をジャンパー線で直結しても、起動ログ・キーボードの抜き差しのログが 1 バイトも届かない。PC からは `1a86:55d4` として見え、+5V の給電は問題なく使えている。
当面、ログは `usb-log` の版で S3 の USB-C から直接読む（[../firmware.md](../firmware.md)）。ログを普段の構成でも見たくなったら買い直す。
