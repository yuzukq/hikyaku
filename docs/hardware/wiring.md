# 配線

## ボードについて

手元の S3 ボードは **ESP32-S3 SuperMini**（AliExpress。Seeed XIAO ではない）。チップは ESP32-S3FH4R2 で、フラッシュ 4MB と PSRAM 2MB を内蔵
（`espflash board-info` は Flash 4MB / Embedded Flash）。ピンには GPIO 番号が印字されているので、ピンは **GPIO 番号**で書く。

ピン配置の図: [image/s3-supermini-pinout.png](image/s3-supermini-pinout.png)（販売元の図）。USB-C を上にして**部品面から**見たとき:

| 左列（上から） | TX(43) | RX(44) | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|---|
| **右列（上から）** | **5V** | **GND** | **3V3** | **13** | **12** | **11** | **10** | **9** | **8** |

- 片側 9 本、列の間隔は 15.24mm（0.6 インチ）。TX と 5V が USB-C の側で向かい合う。
- 裏面にも GPIO14〜18・21・33〜42・45〜48 などのパッドと、電池用のパッド（B+ / B−、充電電流を増やす BOOST ジャンパー）があるが、使っていない。
- GPIO48 は基板上の RGB LED（WS2812 互換）につながっている。

## ピン割り当て

| GPIO | 用途 | 備考 |
|---|---|---|
| 9 | トラックパッド **DR**（Data Ready） | 入力 |
| 10 | トラックパッド **SS**（チップセレクト） | SPI2 の標準 CS |
| 11 | トラックパッド **MOSI** | SPI2 の標準 MOSI |
| 12 | トラックパッド **SCK** | SPI2 の標準 SCLK |
| 13 | トラックパッド **MISO** | SPI2 の標準 MISO |
| 43 (`TX`) | UART0 TX = **ログ出力**（開発中） | CH9102F の RxD へ |
| 44 (`RX`) | UART0 RX | 未使用（つながない） |
| 19 / 20 (USB-C) | **USB ホスト**（D−=19, D+=20） | キーボードを接続 |
| `5V` | 外部から給電 → キーボードにも 5V が届く | 確認済み |
| `3V3` | トラックパッドの電源（2.9mA） | |
| 6 | 本体のボタン（MX スイッチ。もう片方は GND） | 入力、内部プルアップ。押すと Low |
| 7 | （PCB で増やす 2 個目のスイッチ。予定） | ファームは未対応。ユニバーサル基板では基板側の GPIO7 の箇所が壊れていて使えなかった（S3 の GPIO7 は無事） |
| 48 | 基板上の RGB LED | 状態表示（赤 / 緑 / 青） |

避けているピン: GPIO0（BOOT）、GPIO3・45・46（ストラッピング）、19/20（USB）、43/44（UART0）、26〜32（モジュール内のフラッシュ/PSRAM）。

## トラックパッドの配線（SPI 版 TM035035）

12 ピン FFC → 変換基板の番号は、ケーブルの A/B タイプによって**逆順になることがある**。電源を入れる前にテスターで確認する（下記）。
手元の組み合わせでは、**変換基板の印字と J1 の番号が逆順**だった（[assembly.md](assembly.md) の注意を参照）。下の表は J1 の番号。

| J1 | 信号 | S3 |
|---|---|---|
| 1 | SCK | GPIO12 |
| 2 | MISO | GPIO13 |
| 3 | SS | GPIO10 |
| 4 | DR | GPIO9 |
| 5 | MOSI | GPIO11 |
| 6, 7, 8 | BTN2, BTN3, BTN1 | つながない |
| 9, 10 | SCL, SDA | つながない（I²C 用） |
| 11 | GND | GND |
| 12 | VDD 3.3V | **3V3**（5V は不可） |

### 通電前の確認（導通）

- 変換基板の **12 番** ↔ トラックパッド基板の「VDD」パッド
- 変換基板の **11 番** ↔ トラックパッド基板の「GND」パッド

どちらも導通すれば向きは正しい。鳴らなければ逆順の可能性が高い（S3 の出力が電源ピンに当たると壊れる恐れ）。

## 開発中の構成（現在）

```
PC ─USB─ CH9102F ─ +5V ──▶ S3 5V   ─(S3 の USB-C)─ C-C ケーブル ─ 7skb
                 ─ GND ──▶ S3 GND
                 ─ RxD ◀── S3 TX (GPIO43)
                         S3 ──BLE──▶ Mac
```

- S3 の USB-C は **PC につながない**（キーボード専用）。
- ログは PC 側の CH9102F のシリアルポートで読む。
- **TX 同士をつながない**（CH9102F の TxD は S3 の RX につながない。S3 の GPIO は 5V 耐性なし）。

## 書き換えるとき

書き込み手順の詳細は [../firmware.md](../firmware.md)。**BOOT ボタンは不要**（2026-10-20 から。ファームは起動後 3 秒間 USB ホストにならない）。

1. **CH9102F の USB を抜く**（5V はジャンパーなしで直結しているので、つないだまま S3 を PC に挿すと VBUS 同士がぶつかる）。キーボードも S3 から外す
2. `tools/hk flash` を実行してから、S3 の USB-C を PC に挿す
3. 書き込みが終わったら抜いて、キーボードと CH9102F を元に戻す

## 最終形

**組み立て（ユニバーサル基板）の完成形の配線は [assembly.md](assembly.md)。**

```
モバイルバッテリー or PC ─(USB-C)─ CH9102F ─ +5V/GND ─▶ S3 5V/GND ─(USB-C)─ 7skb
                                           └ RxD ◀── S3 TX(GPIO43)（ログ）
トラックパッド TM035035 ─ SPI ─ S3（SCK=12, MISO=13, MOSI=11, SS=10, DR=9, 3V3, GND）
S3 ──BLE──▶ Mac
```

トラックパッドのピン順は [trackpad-tm035035.md](trackpad-tm035035.md)、電源は [power.md](power.md)。
