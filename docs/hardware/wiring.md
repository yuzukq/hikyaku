# 配線

## ボードについて

手元の S3 ボードは **Seeed XIAO ではない**（ピンに GPIO 番号が印字されている。`espflash board-info` は Flash 4MB / Embedded Flash。
型名は未確認で、Super Mini 系と思われる）。このため、ピンは **GPIO 番号**で書く。
ボード上で使えるのは `GPIO1`〜`GPIO13` のほか、`5V` / `GND` / `3V3`、`TX`(=GPIO43) などの印字ピン。

## ピン割り当て

| GPIO | 用途 | 備考 |
|---|---|---|
| 9 | トラックパッド **DR**（Data Ready） | 入力 |
| 10 | トラックパッド **SS**（チップセレクト） | SPI2 の標準 CS |
| 11 | トラックパッド **MOSI** | SPI2 の標準 MOSI |
| 12 | トラックパッド **SCK** | SPI2 の標準 SCLK |
| 13 | トラックパッド **MISO** | SPI2 の標準 MISO |
| 43 (`TX`) | UART0 TX = **ログ出力**（開発中） | CH9102F の RxD へ |
| 44 (`RX`) | UART0 RX | 未使用（つながない） |
| 19 / 20 (USB-C) | **USB ホスト**（D−=19, D+=20） | キーボードを接続 |
| `5V` | 外部から給電 → キーボードにも 5V が届く | 確認済み |
| `3V3` | トラックパッドの電源（2.9mA） | |

避けているピン: GPIO0（BOOT）、GPIO3・45・46（ストラッピング）、19/20（USB）、43/44（UART0）、26〜32（モジュール内のフラッシュ/PSRAM）。

## トラックパッドの配線（SPI 版 TM035035）

12 ピン FFC → 変換基板の番号は、ケーブルの A/B タイプによって**逆順になることがある**。電源を入れる前にテスターで確認する（下記）。

| J1 | 信号 | S3 |
|---|---|---|
| 1 | SCK | GPIO12 |
| 2 | MISO | GPIO13 |
| 3 | SS | GPIO10 |
| 4 | DR | GPIO9 |
| 5 | MOSI | GPIO11 |
| 6, 7, 8 | BTN2, BTN3, BTN1 | つながない |
| 9, 10 | SCL, SDA | つながない（I²C 用） |
| 11 | GND | GND |
| 12 | VDD 3.3V | **3V3**（5V は不可） |

### 通電前の確認（導通）

- 変換基板の **12 番** ↔ トラックパッド基板の「VDD」パッド
- 変換基板の **11 番** ↔ トラックパッド基板の「GND」パッド

どちらも導通すれば向きは正しい。鳴らなければ逆順の可能性が高い（S3 の出力が電源ピンに当たると壊れる恐れ）。

## 開発中の構成（現在）

```
PC ─USB─ CH9102F ─ +5V ──▶ S3 5V   ─(S3 の USB-C)─ C-C ケーブル ─ 7skb
                 ─ GND ──▶ S3 GND
                 ─ RxD ◀── S3 TX (GPIO43)
                         S3 ──BLE──▶ Mac
```

- S3 の USB-C は **PC につながない**（キーボード専用）。
- ログは PC 側の CH9102F のシリアルポートで読む。
- **TX 同士をつながない**（CH9102F の TxD は S3 の RX につながない。S3 の GPIO は 5V 耐性なし）。

## 書き換えるとき

S3 は起動して 3 秒後に USB ホストになり、USB シリアル/JTAG（書き込み用）が使えなくなる。

1. 給電（CH9102F またはバッテリー）の 5V を S3 から外し、キーボードも外す
2. S3 の **BOOT を押しながら** USB-C を PC に挿す（ダウンロードモード）
3. `espflash flash ...`（[../firmware.md](../firmware.md)）
4. 抜いて、キーボードと給電を元に戻す

## 最終形（予定）

```
モバイルバッテリー ─ Type-C DIP 化キット(+CC 5.1kΩ×2) ─▶ S3 5V/GND ─ 7skb
トラックパッド TM035035 ─ SPI ─ S3（SCK=12, MISO=13, MOSI=11, SS=10, DR=9, 3V3, GND）
S3 ──BLE──▶ Mac
```

トラックパッドのピン順は [trackpad-tm035035.md](trackpad-tm035035.md)、電源は [power.md](power.md)。
