## 基板化（2026-10-15 完了）

ブレッドボードのジャンパー線では接触が不安定だったため、ユニバーサル基板にはんだ付けする。配線は [assembly.md](assembly.md)。

| 部品 | 状況 |
|---|---|
| ユニバーサル基板、配線材 | ✅ 手元 |
| ピンソケット（メス）: S3 用 1×9 ×2、CH9102F 用 1×4、FFC 変換基板用 **2×6** | ✅（2026-10-14、基板に実装済み） |
| ピンヘッダ 1×2 + ジャンパーピン（書き込み時に 5V を切る） | 付けなかった（5V は直結。書き込み時は CH9102F の USB を抜く） |
| 0.1µF セラミックコンデンサ（トラックパッドの電源。任意） | 付けなかった（なくても安定して動いている） |

本体のボタン（GPIO6）の MX スイッチも、この基板に付けた（2026-10-22）。

**道具:** 温度調節付きはんだごて、はんだ（0.6〜0.8mm）、フラックス、はんだ吸い取り線、ニッパー、ピンセット、テスター。
