# 電源

## 方針

最終形はモバイルバッテリー（Type-C 出力）から **S3 の 5V ピン**に給電する。
S3 の 5V ピンは USB-C の VBUS と直結しているため、ここに入れた 5V がキーボードにも供給される
（S3 は USB ホスト、キーボードは C-to-C ケーブルで接続）。S3 の USB-C はキーボード専用になる。

```
モバイルバッテリー ──(C-C ケーブル)──▶ Type-C DIP 化キット ──▶ S3 の 5V / GND
                                         └ CC1/CC2 を各 5.1kΩ で GND へ
```

## Type-C DIP 化キット（秋月 AE-USB2.0-TYPE-C-5077CR）

回路図: https://akizukidenshi.com/goodsaffix/AE-USB2.0-TYPE-C-5077CR_schematic.pdf

コネクタ CN1 は 5077CR-16-SM-BK-TR。CN2（7 ピン）への引き出しは次のとおり。

| CN2 | 信号 | 元のコネクタ側 |
|---|---|---|
| 1 | VBUS | A4/A9/B4/B9 を束ねたもの |
| 2 | D− | A7/B7 |
| 3 | D+ | A6/B6 |
| 4 | GND | A1/A12/B1/B12 |
| 5 | CC1 | A5 |
| 6 | CC2 | B5 |
| 7 | GND | 〃 |

SBU1/SBU2 は未接続。**CC1・CC2 に抵抗は載っていない**（2 つとも CN2 に出ているだけ）。

### 必要な追加部品

バッテリー（給電側）から 5V を出させるには、CC1・CC2 をそれぞれ **5.1kΩ で GND へ**落とす必要がある。

- CN2 の 5 番（CC1）— 4 or 7 番（GND）の間に 5.1kΩ
- CN2 の 6 番（CC2）— 4 or 7 番（GND）の間に 5.1kΩ

秋月の共通資料によると、5.1kΩ を正しく付けた場合の CC 電圧は約 0.42V（上限 500mA）／約 0.94V（1.5A）／約 1.68V（3A）で、
流せる電流は電源機器側で決まる。500mA 程度で足りる想定。参考: https://akizukidenshi.com/goodsaffix/powered_by_type-c.pdf

## 確認が必要なこと

- **自動オフ:** 小型バッテリーは負荷電流が小さいと自動で切れる製品がある。S3 + BLE + キーボードで 100mA 前後。実機で数分〜数十分放置して確認する。
- **書き換え時:** バッテリーを S3 の 5V につないだまま S3 を PC に挿さない（VBUS 同士が衝突する）。先に 5V の配線を外す。
- **電流:** キーボードの消費電流は未測定。
