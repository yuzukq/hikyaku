# ショートカットリング（Mac アプリ）構想

**状態: 構想（2026-10-20）。** 起動方法などは未定。

## やりたいこと

hikyaku はトラックパッドが物理的に丸い。そこで、Logi Options+ の「Actions Ring」のような**円形のショートカットリング**を Mac に出し、
パッドの円と画面のリングを対応させて、アクションを選べるようにする。

- Mac 側に **hikyaku のフロントエンドとなるネイティブアプリ**を作る（Swift / SwiftUI、AppKit）。
- リングを出している間は、パッドに**触れている位置**をリング上にリアルタイムで表示する（視覚フィードバック）。
- リングに割り当てるアクション（アプリの起動、ショートカットキー、メディア操作、スクリプトなど）を、**GUI で編集**できる。
- 見た目は Apple のデザインパターンに合わせる（Human Interface Guidelines。SF Symbols、vibrancy の素材、標準の設定画面の作り）。

## 技術的に考えること

### 1. 触れている位置をどう取るか（ファーム）

今のファームは**相対モード**（移動量だけ）で、指の位置は取れない。リングには**絶対位置**が要る。

- Pinnacle は相対モードと絶対座標モードを同時には使えない。**リングを出している間だけ絶対座標モードに切り替える**（終わったら相対モードに戻す）。
  - 切り替えのたびに FeedConfig を書き換える。キャリブレーションはやり直さなくてよいはず（要確認）。
- 絶対座標の読み方と、Y の bit11 が別のフラグになっている問題（11 ビットにマスクする）は、タグ `absolute-mode-last` のコードに残っている。
- リングに必要なのは、中心からの**角度**（どのセクタか）と**距離**（中心付近 = キャンセル、など）だけでよい。
  丸いパッドの角度にそのまま対応させるので、「長方形の画面に対応させる」問題は起きない。
- 位置の補正（パッドの中心と半径）は、実機の座標の範囲から決める。パッドが 90° 回って付いている分も補正する。

### 2. Mac アプリにどう届けるか（通信）

- HID のマウスレポートとは別に、**独自の BLE GATT サービス**（ベンダー UUID）を作り、位置（角度・距離・接触の有無）を notify で流す。
  OTA で独自サービスを作った実績がある（`OtaService`）。
- Mac アプリは CoreBluetooth で、**すでに接続済み**の hikyaku（`retrieveConnectedPeripherals(withServices:)`）の独自サービスを購読する。
  HID としての接続は macOS が持ったままでよい（要検証: macOS が HID デバイスの独自サービスにアプリから触らせるか）。
- だめなら、USB 経由（PC に挿すとき）や、HID の Vendor-defined レポートで流す方法を検討する。

### 3. 起動方法（未定。候補）

| 候補 | 良い点 | 気になる点 |
|---|---|---|
| 7sPro の特定のキー（またはキーの組み合わせ）を押している間 | 確実。誤動作しない | キーを 1 つ使う |
| パッドの長押し（一定時間、ほぼ動かさずに触れ続ける） | パッドだけで完結 | 普通のカーソル操作と区別が要る |
| パッドの縁をなぞり始めたら | 丸いパッドらしい | 判定が難しい。2 本指スクロールの代わりの「縁で円スクロール」と取り合う |
| Mac アプリのショートカット | ファームの変更が少ない | 両手が要る |

ファームが起動を判定する場合は、Mac アプリへ「リング開始／終了」を同じ独自サービスで通知する。
リングを出している間は、マウスの移動レポートを止める（カーソルを動かさない）。

### 4. アクションの実行（Mac アプリ）

- ショートカットキーの送出、アプリの起動、AppleScript / Shortcuts.app の実行など。
  アクセシビリティ権限（キー送出）が要る。
- 設定はアプリ側に保存する（ファームは位置を送るだけ。アクションを知らない）。アプリごとにリングを切り替える案もある（Options+ と同じ）。

## 進め方（案）

1. ファーム: 絶対座標モードへの切り替えと、位置の独自 GATT サービス（まずは常時流す試作）
2. Mac: CoreBluetooth で接続済みの hikyaku から位置を受け取り、円の上に点を出すだけの試作 → **macOS が HID デバイスの独自サービスにアクセスさせるか**をここで確かめる
3. 起動方法を決めて、ファームの切り替えを実装
4. リングの UI（SwiftUI、オーバーレイのウィンドウ）とアクションの実行
5. 設定画面（アクションの割り当ての編集）
